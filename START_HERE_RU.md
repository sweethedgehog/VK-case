# Запуск HSEHelper на Windows без VPS

## 1. Установка

1. Распакуй архив в обычную папку, например `C:\Users\kripe\PycharmProjects\HSEHelper-local`.
2. Дважды нажми `install_local.bat`. Дождись сообщения `Setup complete`.
3. Открой `.env` и вставь ключ Gemini в `GEMINI_API_KEY`. Не публикуй этот файл в GitHub.
4. Если `data/courses.json` отсутствует, запусти `collect_courses.bat`. Это требует доступа к сайту ВШЭ.
5. Запусти `start_site.bat`, оставь окно открытым и открой `http://127.0.0.1:8000`.

## 2. Что делать, если запуск не удался

Скопируй последние 15–25 строк ошибки из чёрного окна. Не присылай `.env`, ключ Gemini или токен Telegram.

## 3. Основные файлы

- `scrape_hse.py` — собирает публичные программы дисциплин ВШЭ.
- `data/courses.json` — локальная копия собранных программ.
- `query_utils.py` — нормализует вопросы и знает несколько студенческих сокращений.
- `semantic_search.py` — ищет подходящие фрагменты по тексту курсов.
- `assistant.py` — строит ответ с помощью Gemini и источников.
- `server.py` — сайт и HTTP API.
- `bot.py` — дополнительный Telegram-клиент; его запуск не нужен для веб-демонстрации.

Код лучше оставить понятным, чтобы ты мог объяснить его на защите. Комментарии, которые поясняют важные ограничения или безопасность, полезнее удалять выборочно, а не делать проект намеренно запутанным.


## Telegram-бот

Ссылка на бот: **https://t.me/HSEHelperIVTbot**. Для проверки в Telegram открой ссылку и нажми «Start».

Чтобы бот отвечал в текущем локальном варианте, нужно держать открытыми два процесса на компьютере:
- первое окно: `start_site.bat`;
- второе окно: `start_telegram_bot.bat`.

Токен указывается в `.env` как `TELEGRAM_BOT_TOKEN=...`. Его нельзя отправлять в чат или коммитить в GitHub. Если компьютер выключен, спит или не может подключиться к `api.telegram.org`, бот не ответит. Для короткой демонстрации запусти оба процесса перед проверкой и не закрывай окна.

## Что требуется от тебя перед сдачей

1. Убедиться, что `data/courses.json` создан для первого курса 2026/2027 и содержит официальные URL.
2. Запустить `run_local_tests.bat`.
3. Запустить сайт и выполнить 30-вопросный прогон по команде из README; вручную оценить каждый ответ.
4. Опубликовать код в GitHub как `Public`, не добавляя `.env`, секреты, `.venv`, `data/courses.json` и SQLite-историю.
5. Приложить ссылку на репозиторий, фактический отчёт на 30 вопросов и `docs/Презентация_HSEHelper.pptx`.
