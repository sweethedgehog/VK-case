# HSEHelper — локальный помощник первокурсника ИВТ МИЭМ НИУ ВШЭ

Эта версия предназначена для сдачи и демонстрации **без VPS, SSH и Docker**. Сайт и API запускаются на твоём Windows-компьютере в PyCharm; сайт открывается только локально по адресу `http://127.0.0.1:8000`. Telegram-бот подключается дополнительно и работает лишь при наличии доступа к Telegram API из текущей сети.

**ТЗ:** брать дисциплины только 1 курса за 2026/2027 учебный год из официального каталога: <https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026>.

## Самый быстрый запуск на Windows

Нужно: Python 3.12 (или 3.11), ключ Gemini API и доступ к интернету для сайта ВШЭ/Gemini. Удалённый сервер не нужен.

1. Распакуй архив в папку, например `C:\Users\<твой_пользователь>\PycharmProjects\HSEHelper`.
2. Дважды щёлкни `install_local.bat`. Он создаст `.venv`, поставит облегчённые зависимости и создаст `.env` из `.env.local.example`.
3. Открой `.env` и замени `GEMINI_API_KEY=put_your_key_here` на свой ключ из <https://aistudio.google.com/apikey>. Не присылай и не коммить ключ.
4. Если у тебя уже есть рабочий `data/courses.json` из старого проекта — скопируй его в папку `data` новой версии. Если файла нет, дважды щёлкни `collect_courses.bat`.
5. Дважды щёлкни `start_site.bat`.
6. Открой <http://127.0.0.1:8000>. Документация API доступна по адресу <http://127.0.0.1:8000/docs>, проверка процесса — <http://127.0.0.1:8000/health>.

Оставь окно `start_site.bat` открытым, пока демонстрируешь сайт. Закрытие этого окна остановит локальный API и сайт.

## Почему эта версия не скачивает Hugging Face

В `.env` для дедлайна используется `SEARCH_MODE=keyword`. Это отключает автоматическую загрузку локальной embedding-модели и использует резервный локальный поиск по словам, названиям дисциплин и словарю сокращений. Поэтому первый запуск не зависнет на скачивании `sentence-transformers` из Hugging Face.

Ответы всё ещё формирует Gemini API по фрагментам из локального `data/courses.json`; для этого нужен интернет и действующий API-ключ. Если захочешь включить полноценный смысловой поиск embeddings после сдачи, поставь полный набор зависимостей (`pip install -r requirements.txt`) и поменяй `SEARCH_MODE=keyword` на `SEARCH_MODE=auto` в `.env`. Тогда потребуется загрузить модель из Hugging Face.

## Если каталог уже собран

Если `data/courses.json` был собран в твоём прежнем проекте, **не запускай сбор заново без необходимости**: скопируй этот файл в `data/courses.json` новой версии. Убедись, что записи содержат официальный URL и относятся к 2026/2027 учебному году.

Чтобы собрать каталог заново, выполни:

```powershell
.venv\Scripts\python.exe scrape_hse.py --limit 30 --max-pages 5 --year 2026 --course-filter 1.1.1.4
```

`--limit 30` — ограничение числа страниц/дисциплин для прототипа, а не гарантия полноты каталога. После сбора проверь `data/courses.json`.

## Запуск через PyCharm

В настройках проекта выбери интерпретатор `HSEHelper\.venv\Scripts\python.exe`. В терминале PyCharm:

```powershell
.venv\Scripts\Activate.ps1
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

После запуска открой `http://127.0.0.1:8000` в браузере.

Публичная ссылка для демонстрации: **[@HSEHelperIVTbot](https://t.me/HSEHelperIVTbot)**. Проверяющий может открыть ссылку в Telegram и нажать «Start».

1. `start_site.bat` — сайт и API на `http://127.0.0.1:8000`;
2. `start_telegram_bot.bat` — получение сообщений от Telegram.

Оба окна терминала нужно оставить открытыми; компьютер должен быть включён и иметь доступ к `api.telegram.org`. Если закрыть процесс или компьютер уйдёт в сон, бот временно перестанет отвечать. Токен Telegram не публикуется в репозитории и хранится только в `.env`.

Если бот ещё не настроен на конкретном компьютере:

1. Создай или используй существующего бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Добавь его в `.env` в строку `TELEGRAM_BOT_TOKEN=...`.
3. Запусти `install_telegram.bat` один раз.
4. Сначала запусти `start_site.bat`, затем во втором окне — `start_telegram_bot.bat`.

Бот — дополнительный интерфейс. Для сдачи проекта сайт можно демонстрировать отдельно, но если в материалах указан Telegram-бот, проверь его в момент демонстрации.

## Фактический прогон по 30 вопросам

В `benchmark_cases.json` находится набор из 30 кейсов: 20 вопросов на проверку полезности и 10 сценариев, показывающих ограничения. При работающем API, собранном каталоге и настроенном Gemini выполни:

```powershell
.venv\Scripts\python.exe run_benchmark.py --url http://127.0.0.1:8000 --delay 4.5 --output docs/Результаты_фактического_прогона.md
```

Скрипт сохраняет реальные ответы, статусы и источники. После прогона оцени каждый ответ `PASS`, `PARTIAL` или `FAIL` по критериям `docs/Тестирование_30_вопросов.md`. Если бесплатная квота Gemini закончилась, зафиксируй это в результатах, не выдавай шаблонные ожидаемые ответы за реальный прогон.

## API

- `GET /health` — проверка доступности локального API.
- `GET /api/status` — состояние каталога.
- `GET /api/courses` — список собранных дисциплин.
- `POST /api/ask` — вопрос помощнику.
- `GET /docs` — Swagger UI.

Пример тела `POST /api/ask`:

```json
{
  "question": "Что изучают на математическом анализе?",
  "session_id": "demo-001"
}
```

Ответ содержит `answer`, `sources` и `session_id`.

## Структура

- `scrape_hse.py` — сбор публичных страниц программ ВШЭ.
- `query_utils.py` — сокращения, алиасы, поиск преподавателей.
- `assistant.py` — контекст, локальный поиск и вызов Gemini.
- `semantic_search.py` — разбиение текста и семантический индекс (опционально).
- `server.py` — локальный сайт и API.
- `bot.py` — необязательный Telegram-бот.
- `conversation_store.py` — локальная история диалогов SQLite.
- `web/` — файлы интерфейса.
- `docs/` — тестовые вопросы, источники, презентация.

## Честные ограничения

1. Локальный сайт открывается на твоём компьютере, а не по публичному IP; так можно демонстрировать и проверять прототип без VPS.
2. Gemini API требует интернет и корректный ключ. Бесплатные квоты/доступность моделей могут меняться.
3. Поиск в режиме `keyword` быстрее стартует, но слабее понимает перефразировки, чем embeddings. Можно переключить `SEARCH_MODE=auto` после настройки Hugging Face.
4. Парсер собирает только публично доступный текст; он не открывает LMS и не гарантирует распределение преподавателей по группам, если на странице программы этой информации нет.
5. Каталог ограничен фактически собранными страницами. Всегда показывай пользователю официальные ссылки на источники.
