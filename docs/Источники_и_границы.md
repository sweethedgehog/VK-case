# Источники и границы данных

## Основной источник

Каталог учебных дисциплин образовательной программы ИВТ МИЭМ НИУ ВШЭ с фильтром первого курса за 2026/2027 учебный год: 

<https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026>

Парсер формирует URL каталога с параметрами `course=1.1.1.4`, `year=2026`, `page=N`, затем собирает ссылки на публичные страницы дисциплин с домена `hse.ru`.

## Примеры публичных программ

- [Математический анализ](<https://www.hse.ru/ba/isct/courses/1197128651.html>) — сведения о кредиты, модулях, содержании, контроле, промежуточной аттестации, литературе и преподавателях.
- [Алгебра и геометрия](<https://www.hse.ru/ba/isct/courses/1197128571.html>) — содержание по линейной алгебре и аналитической геометрии, формы контроля, связи с другими дисциплинами.
- [Алгоритмизация и программирование](<https://www.hse.ru/ba/isct/courses/1197128565.html>) — основы алгоритмизации, C/C++, структуры данных, сложность алгоритмов, контроль.
- [Введение в специальность](<https://www.hse.ru/ba/isct/courses/1197128541.html>) — цели, темы знакомства с инфраструктурой МИЭМ, элементы контроля и формула оценивания.
- [Дискретная математика](<https://www.hse.ru/ba/isct/courses/1197128559.html>) — общие сведения, кредиты, модули.

## Ограничения данных

1. Загружаются только публичные страницы; закрытые материалы LMS не читаются.
2. Лимит `--limit 30` означает выборку из каталога, а не гарантированно полный учебный план.
3. Список преподавателей на странице курса не означает распределение лекторов и семинаристов по академическим группам. Для такого ответа нужен отдельный источник распределения занятий, который не входит в это ТЗ.
4. Данные представляют снимок на момент парсинга. Обновления сайта не отражаются до следующего запуска сборщика.
5. Формулы оценивания следует цитировать именно в том виде, как их публикует ВШЭ; если формула выглядит неполной или неоднозначной, помощник должен сообщить об этом, а не исправлять её без оснований.
