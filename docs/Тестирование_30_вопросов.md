# Тестирование HSEHelper на 30 вопросах

**Назначение:** набор сценариев для демонстрации сильных сторон и известных ограничений прототипа в рамках ТЗ.

> **Важно о статусе.** Эталонные ответы ниже подготовлены по публичным страницам ВШЭ. В текущей среде пройдены автоматические smoke-тесты кода и HTTP API, но полный прогон 30 запросов через работающий экземпляр Gemini + актуальный `data/courses.json` не выполнялся. Не выдавайте эталонные ответы за фактические ответы модели. Чтобы получить фактический протокол, сначала запустите сборщик и API, затем выполните `python run_benchmark.py --url http://127.0.0.1:8000 --delay 4.5 --output docs/Результаты_фактического_прогона.md`.

## Предварительные технические проверки

- `python -m py_compile ...` — пройдено для основных Python-модулей.
- `python tests.py` — **пройдено**: `Все smoke tests пройдены.`
- `python api_smoke_tests.py` — **пройдено**: `HTTP smoke tests passed.`
- 30 вопросов ниже — эталонный функциональный набор; результаты модели нужно записать отдельным фактическим прогоном.
